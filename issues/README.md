# Local Issue Tracker

This folder is a simple local issue system for managing work without GitHub.

## Structure
- `backlog/`: not started
- `in-progress/`: currently active
- `done/`: completed

## Workflow
1. Create one Markdown file per issue.
2. Move the file between folders as status changes.
3. Update the frontmatter and checklist as you work.
4. Reference issue IDs in commit messages when useful.

## Naming
Use: `NNN-short-title.md`

Example: `001-update-pydev-with-ml-projects.md`
