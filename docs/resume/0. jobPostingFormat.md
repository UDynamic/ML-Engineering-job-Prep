# Job Posting Save Format (`jobPostings/`)

Use **one file per job posting** in Markdown format.

## Filename Convention
`YYYY-MM-DD_source_company_role_location.md`

Example:
`2026-03-20_jobinja_pishro-ebtekar-danesh_data-science-engineer_tehran.md`

## Reusable Template

```md
---
source: jobinja.ir
url: ""
saved_at: YYYY-MM-DD
language: fa|en|mixed

company_fa: ""
company_en: ""
company_size: ""
company_website: ""
company_intro: ""

role_title: ""
role_category: ""
location_city: ""
location_province: ""
work_type: remote|hybrid|on-site
employment_type: full-time|part-time|contract
seniority_min_experience: ""
salary: ""

required_gender: ""
military_status_requirement: ""
minimum_education: ""

status: open|closed|unknown
---

## Job Summary
(2-5 lines clean summary of role mission and scope)

- ...

- ...

- ...

- ...

  - ...
```

```md
## Job Summary
Engineering-focused data/AI role for sensor-based diagnostics, condition monitoring, and profilometry analysis.
The role combines signal processing, anomaly detection, and cross-team collaboration with machine vision.

## Responsibilities
- Develop signal-processing algorithms for time-series and profile data (FFT, filtering, spectral analysis, envelope detection, trend decomposition).
- Build/validate threshold and event-detection logic for maintenance triggers.
- Integrate multi-sensor inputs into consolidated condition metrics.
- Evaluate ML/hybrid (rules + ML) anomaly detection approaches and production steps.
- Validate sensor quality, calibration checks, and KPI data lineage.
- Support root-cause investigations and KPI refinement.
- Collaborate with machine vision team on extracted variables and measurement feedback.
- Investigate anomalies, inconsistencies, and data quality issues.
- Prepare technical documentation and analytical reports.

## Requirements
- Bachelor’s+ in Mechanical/Electrical/Mechatronics/Signal Processing or related.
- Strong math + signal processing (time/frequency domain, filtering, FFT/PSD, envelope analysis, cross-correlation).
- Python proficiency with NumPy/SciPy.
- Ability to interpret sensor behavior and extract actionable insights.
- Strong documentation and task-tracking discipline.
- Independent execution + effective team collaboration.
- Professional English for technical docs/papers/standards and reporting.
- Strong curiosity, proactive learning, fast adaptation to new domain knowledge.

## Preferred Qualifications
- Fault diagnosis/detection familiarity.
- Experience with sensor/engineering datasets (acceleration, vibration, video profiling).
- Signal-quality metrics, trend analysis, event detection.
- Condition-monitoring and vibration-analysis tooling.
- Profilometry / point-cloud / laser-scanner / precision measurement workflows.
- MATLAB experience.
- AI/ML workflow experience.
- Basic computer-vision familiarity.

## Personal & Ethical Qualities
- Teamwork and cross-functional communication.
- Ownership and growth mindset.
- Organization, responsibility, prioritization.
- Systems thinking.
- Clear technical presentation/reporting.
- Analytical problem-solving attitude.
- Commitment, perseverance, attention to detail.
- Creative data-driven insight generation.

## Working Conditions

- Sunday to Thursday.
- Flexible project-based schedule.
- Remote employment type.

- Data Science
```
